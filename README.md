# passgen

Терминальный генератор паролей с TUI и зашифрованной памятью (историей).
Java, только стандартная библиотека JDK — ноль внешних зависимостей.

## Возможности

- Генерация паролей: длина, наборы символов (заглавные/строчные/цифры/символы),
  исключение похожих символов (`Il1O0o...`), гарантия по одному символу
  из каждого выбранного набора + перемешивание (`SecureRandom`).
- Память: история сохранённых паролей с метками, зашифрована **AES-256-GCM**,
  ключ получается из мастер-пароля через **PBKDF2WithHmacSHA256** (210k итераций).
  Всё — `javax.crypto` / `java.security` из JDK, без сторонних библиотек.
- Настройки (длина по умолчанию, наборы символов, тема) хранятся отдельно,
  открытым текстом в `~/.warden/settings.properties` — там нет паролей.
- 5 тем оформления (ANSI 256 цветов): Everforest, Gruvbox, Nord, Dracula, Solarized —
  как в остальных терминальных тулзах.
- Опциональное копирование в буфер обмена (`java.awt.Toolkit`) — работает, если
  есть графическая сессия (X11/Wayland); иначе просто предупреждение, без падения.

## Сборка и запуск

Нужен JDK 17+ (использую switch-выражения, `Path.of`, `String.repeat`).

```sh
make run          # собрать и сразу запустить
# или вручную:
javac -d out src/warden/*.java
java -cp out warden.Main

# собрать раннабельный jar:
make jar
java -jar warden.jar
```

## Хранение данных

- `~/.warden/vault.dat` — зашифрованная история (формат: `WRD1` + salt(16) + iv(12) + AES-GCM ciphertext).
- `~/.warden/settings.properties` — настройки, обычный текст.

Мастер-пароль нигде не хранится и не может быть восстановлен — забыл его,
значит история не расшифровывается. Это осознанный компромисс, а не баг.

## Структура

```
src/warden/
  Main.java              — TUI-цикл, все сценарии (генерация/история/настройки)
  PasswordGenerator.java — сама генерация
  Vault.java              — AES-GCM шифрование/расшифровка истории
  VaultEntry.java          — запись истории (метка, пароль, дата)
  VaultException.java      — ошибки хранилища
  Settings.java             — persist настроек (java.util.Properties)
  Theme.java                — ANSI-темы
  ConsoleUI.java             — хелперы TUI (рамки, промпты, скрытый ввод пароля)
```
