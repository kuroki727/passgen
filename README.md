# 🇬🇧 English

`passgen` is a small, fast, dependency-free password generator for the
terminal. It generates cryptographically secure passwords and Diceware-style
passphrases, checks them against [Have I Been Pwned](#-hibp-check) without
leaking the password, keeps an [encrypted history](#-history), and ships as
a **single native binary** — no JVM required at runtime.

```
$ passgen -l 24 -s -e
J7#kQ2!vN8@pL5$xR3&mZ6*   (145.3 bits)
```

## ✨ Features

| | Feature |
|---|---|
| 🔒 | **Cryptographically secure** — `SecureRandom`, Fisher–Yates shuffle |
| ⚡ | **Native binary** — ~5 ms startup, no JVM, no runtime dependencies |
| 🎨 | **Interactive TUI** — regenerate, toggle classes, copy, save, view history |
| 🌍 | **Have I Been Pwned** — k-anonymity check, password never leaves the machine |
| 🗄️ | **Encrypted history** — `age` or `gpg`, plaintext fallback at mode 0600 |
| 🐚 | **Shell completions** — bash, zsh, fish (generated by the binary itself) |
| 🧩 | **Passphrase mode** — Diceware-style, uses `/usr/share/dict/words` if present |
| ⚙️ | **Config file** — `~/.config/passgen/config` with sensible defaults |
| 🎯 | **Guaranteed class coverage** — at least one char from every enabled class |
| 🚫 | **No ambiguous chars** — `--no-ambiguous` removes `i l 1 L o 0 O \| \` ' "` |
| 📦 | **Deb / RPM / Homebrew** — ready-to-use packaging recipes |
| 🧪 | **Tested** — 13 unit tests including distribution uniformity |

## 📦 Installation

### Option 1 — Prebuilt binary (recommended)

Download the latest release for your platform from the
[Releases page](https://github.com/yourname/passgen/releases):

```bash

curl -L https://github.com/yourname/passgen/releases/latest/download/passgen-linux-x86_64.tar.gz \
  | tar xz -C /tmp

sudo mandb -q
```

### Option 2 — Homebrew (macOS / Linux)

```bash

```

### Option 3 — Debian / Ubuntu (native .deb, no Java)

```bash
git clone https://github.com/yourname/passgen
cd passgen
./build.sh              # needs GraalVM
./packaging/fpm.sh      # needs fpm
sudo dpkg -i target/dist/passgen_*.deb
```

### Option 4 — Build from source

See [Building from source](#-building-from-source).

### Optional runtime tools

| Tool | Purpose | Install |
|---|---|---|
| `age` | preferred encrypted history | `brew install age` / `apt install age` |
| `gpg` | fallback encrypted history | usually preinstalled |
| `xclip` / `xsel` / `wl-clipboard` | `-c` clipboard support | `apt install xclip` |
| `/usr/share/dict/words` | larger word list for passphrases | `apt install wamerican` |

Without `age` or `gpg`, history is stored as **plaintext with mode 0600** and
a warning is printed on the first write.

## 🎨 Interactive TUI

Launch with `passgen tui` (or `passgen t`).

| Key | Action |
|---|---|
| `g` | regenerate |
| `c` | copy to clipboard |
| `k` | check against HIBP |
| `i` | type a new length (Enter confirm, ESC cancel) |
| `h` | history view (`C` to clear, `q` to return) |
| `l` / `L` | length −1 / +1 |
| `w` `u` `d` `s` `a` | toggle lower / upper / digits / symbols / no-ambiguous |
| `r` | toggle record-to-history |
| `S` | save config + record current password |
| `q` | quit |

The TUI is safe: it refuses to disable the last enabled character class, and
restores terminal state on exit (even on Ctrl-C).

## ⚙️ Configuration

Location: `~/.config/passgen/config` (or `$XDG_CONFIG_HOME/passgen/config`).

```bash
passgen config init      # write defaults
passgen config show      # print current
passgen config edit      # open in $EDITOR
passgen config path      # print the path
```

Example:

```ini
# passgen configuration
length = 24
count = 1
lower = true
upper = true
digits = true
symbols = true
no_ambiguous = false
passphrase_words = 0
entropy = true
record_history = true
```

CLI flags always override the config.

## 🗄️ History

Generated passwords are appended to an encrypted log. Backend is chosen
automatically:

| Priority | Backend | File | Condition |
|---|---|---|---|
| 1 | `age` | `~/.local/share/passgen/history.age` | `age` + `age-keygen` on PATH |
| 2 | `gpg` | `~/.local/share/passgen/history.gpg` | `gpg` on PATH |
| 3 | plaintext | `~/.local/share/passgen/history` | fallback, mode 0600 |

Force a backend with `PASSGEN_HISTORY_BACKEND=age|gpg|plain|none`.

```bash
passgen history list       # show entries
passgen history clear      # wipe all files
passgen history init-key   # create age key (auto-created on first use)
passgen history backend    # print active backend
```

Disable recording per-command with `--no-history`, or permanently via
`record_history = false` in the config or `r` in the TUI.

> **Note** — without `age`/`gpg`, the file is plaintext. It is created with
> mode `0600` and a warning is printed, but it is **not** encrypted.

## 🛡️ HIBP check

`passgen check` verifies a password against
[Have I Been Pwned](https://haveibeenpwned.com/Passwords) using
**k-anonymity**: only the first 5 hex characters of the SHA-1 hash are sent.
The password itself never leaves the machine.

```bash
$ passgen check hunter2
checking hibp...
  found in 24797 breach(es) — do NOT use
$ echo $?
1

$ passgen check 'correct horse battery staple'
checking hibp...
  not found in any known breach ✓
$ echo $?
0
```

If the network is unavailable, `passgen` prints `check failed (no network?)`
and exits with code `0` (it does not claim the password is safe).

## 🧭 Design principles

- **No runtime dependencies.** A `passgen` binary must work on a minimal
  container, a fresh macOS, or a headless server.
- **No surprises.** If something cannot be done safely (encryption, network
  check), it fails loudly rather than silently downgrading.
- **Unix-y.** stdin/stdout/stderr, exit codes, `$EDITOR`, `$XDG_*`, `$PATH`.
- **Boring cryptography.** Use `SecureRandom`; never invent a PRNG.

## ❓ FAQ

<details>
<summary><b>Why Java?</b></summary>

Single language for CLI logic, tests, and native compilation via GraalVM.
The output is a real ELF/Mach-O binary — Java is only a build-time tool.

</details>

<details>
<summary><b>Why not just use <code>openssl rand -base64 24</code>?</b></summary>

You can. `passgen` adds class guarantees, entropy estimation, clipboard
support, an encrypted history, a TUI, and a HIBP check.

</details>

<details>
<summary><b>Is the password ever sent over the network?</b></summary>

Only for `passgen check`, and even then only the first 5 hex chars of the
SHA-1 hash. Generation is fully offline.

</details>

<details>
<summary><b>Where is the history stored?</b></summary>

`~/.local/share/passgen/`. See [History](#-history).

</details>

<details>
<summary><b>It says "no clipboard tool found"</b></summary>

Install `xclip` (X11), `wl-clipboard` (Wayland), or `xsel`.

</details>

<details>
<summary><b>Can I use it on Windows?</b></summary>

Generation works. TUI does not (uses `stty`). Clipboard falls back to AWT.

</details>

Путь: `~/.config/passgen/config` (или `$XDG_CONFIG_HOME/passgen/config`).

```bash
passgen config init      # записать дефолты
passgen config show      # показать текущий
passgen config edit      # открыть в $EDITOR
passgen config path      # вывести путь
```

Пример:

```ini
# конфигурация passgen
length = 24
count = 1
lower = true
upper = true
digits = true
symbols = true
no_ambiguous = false
passphrase_words = 0
entropy = true
record_history = true
```

Флаги CLI всегда перекрывают значения из конфига.

## 🗄️ История

Сгенерированные пароли добавляются в зашифрованный журнал. Бэкенд
выбирается автоматически:

| Приоритет | Бэкенд | Файл | Условие |
|---|---|---|---|
| 1 | `age` | `~/.local/share/passgen/history.age` | `age` + `age-keygen` в PATH |
| 2 | `gpg` | `~/.local/share/passgen/history.gpg` | `gpg` в PATH |
| 3 | plaintext | `~/.local/share/passgen/history` | fallback, права 0600 |

Принудительный выбор: `PASSGEN_HISTORY_BACKEND=age|gpg|plain|none`.

```bash
passgen history list       # показать записи
passgen history clear      # удалить все файлы
passgen history init-key   # создать age-ключ (создаётся автоматически)
passgen history backend    # показать активный бэкенд
```

Отключить запись для одной команды — `--no-history`, или постоянно — через
`record_history = false` в конфиге либо клавишей `r` в TUI.

> **Внимание** — если ни `age`, ни `gpg` не установлены, файл пишется в
> открытом виде. Он создаётся с правами `0600` и печатается
> предупреждение, но он **не** зашифрован.

## 🛡️ Проверка HIBP

`passgen check` проверяет пароль по базе
[Have I Been Pwned](https://haveibeenpwned.com/Passwords) через
**k-anonymity**: наружу уходят только первые 5 hex-символов SHA-1-хеша.
Сам пароль остаётся на машине.

```bash
$ passgen check hunter2
checking hibp...
  found in 24797 breach(es) — do NOT use
$ echo $?
1

$ passgen check 'correct horse battery staple'
checking hibp...
  not found in any known breach ✓
$ echo $?
0
```

Если сети нет, утилита печатает `check failed (no network?)` и завершается
с кодом `0` (она не выдаёт «не найден» за «безопасен»).


## 🧭 Принципы дизайна

- **Никаких рантайм-зависимостей.** Бинарник `passgen` должен работать в
  минимальном контейнере, на чистом macOS и на headless-сервере.
- **Никаких сюрпризов.** Если что-то нельзя сделать безопасно (шифрование,
  сетевая проверка) — утилита падает громко, а не молча деградирует.
- **Unix-way.** stdin/stdout/stderr, коды возврата, `$EDITOR`, `$XDG_*`, `$PATH`.
- **Скучная криптография.** Только `SecureRandom`, никаких самодельных PRNG.

## ❓ FAQ

<details>
<summary><b>Почему Java?</b></summary>

Один язык для логики CLI, тестов и нативной компиляции через GraalVM.
На выходе — настоящий ELF/Mach-O бинарник. Java нужна только на этапе
сборки.

</details>

<details>
<summary><b>Чем не устроит <code>openssl rand -base64 24</code>?</b></summary>

Ничем, если вам этого достаточно. `passgen` добавляет гарантию по классам
символов, оценку энтропии, буфер обмена, зашифрованную историю, TUI и
проверку по HIBP.

</details>

<details>
<summary><b>Пароль куда-то отправляется по сети?</b></summary>

Только при `passgen check`, и то — лишь первые 5 hex-символов SHA-1-хеша.
Генерация полностью офлайновая.

</details>

<details>
<summary><b>Где хранится история?</b></summary>

`~/.local/share/passgen/`. См. [История](#-история).

</details>

<details>
<summary><b>Пишет «no clipboard tool found»</b></summary>

Поставьте `xclip` (X11), `wl-clipboard` (Wayland) или `xsel`.

</details>

<details>
<summary><b>Работает на Windows?</b></summary>

Генерация — да. TUI — нет (использует `stty`). Буфер обмена уходит в AWT.

</details>
